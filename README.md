# Manual Routing

A short deduction game about working as a controller in a broken transit terminal.

The automatic routing system has failed.  
Now every arriving traveler must be assigned manually.

Your job is to listen carefully, inspect symbols and documents, and decide where each person should be sent.

A single mistake may send someone to the wrong sector.  
Too many mistakes, and your shift is over.

## High Concept

**Manual Routing** is a compact atmospheric deduction game where the player works at a transit checkpoint and classifies travelers using fragments of language, symbols, stamps, and visual clues.

The core idea is simple:

- a traveler arrives
- they speak in an unfamiliar language
- their documents show limited clues
- the system is down
- you must decide which destination sector they belong to

The gameplay is about pattern recognition, memory, and judgment under pressure.

## Premise

You are a temporary controller at **Terminal 7**, a transit hub connecting several neighboring states.

Normally, traveler routing is handled by an automated classification system.  
Tonight, that system has failed.

With the network unstable and the queue growing, manual sorting has been activated for the first time in years.

You are given only partial tools:
- spoken phrases
- document colors
- route symbols
- stamps and seals
- occasional notices from central control

At first, the rules seem manageable.  
Then exceptions begin to appear.

## Gameplay

Each traveler provides a combination of clues:
- spoken language pattern
- passport or transit card
- symbol, seal, or route mark
- special conditions or restrictions

The player must:
- inspect the clues
- identify the correct destination
- send the traveler to the correct sector

Correct decisions increase shift performance.  
Incorrect decisions cause strikes.  
Too many strikes end the shift.

As the game progresses:
- more regions are introduced
- language patterns become less obvious
- forged or mixed documents appear
- contradictory clues force harder decisions

## Core Features

- deduction-based gameplay
- fictional regions and language patterns
- increasing difficulty across shifts
- document and symbol recognition
- accuracy / strike system
- replayable short sessions
- atmospheric terminal presentation

## Setting

The game takes place in a fictional transit terminal serving multiple states and border sectors.

This world is not based on real countries directly.  
Instead, it uses fictional regions with distinct:
- language rhythms
- phonetic patterns
- visual identities
- official route symbols

That allows the game to focus on deduction and worldbuilding rather than real-world accuracy.
